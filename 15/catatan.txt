1. Masuk ke folder file pcap
cd ~/Downloads
2. Cek file pcap
ls
Pastikan ada:
soal15_wired_usb_hid.pcap
3. Cek tshark dari Wireshark
/Applications/Wireshark.app/Contents/MacOS/tshark --version
4. Ambil data USB HID keyboard
/Applications/Wireshark.app/Contents/MacOS/tshark -r soal15_wired_usb_hid.pcap -Y "usb.capdata && usb.device_address==7" -T fields -e frame.number -e usb.capdata
5. Simpan hasil capture HID
/Applications/Wireshark.app/Contents/MacOS/tshark -r soal15_wired_usb_hid.pcap -Y "usb.capdata && usb.device_address==7" -T fields -e usb.capdata > hid.txt
6. Melihat data HID
cat hid.txt
7. Decode USB HID Keyboard
Byte pertama = modifier (Shift/Ctrl)
Byte ketiga = keycode karakter
Data 0000000000000000 diabaikan karena tidak ada input
Contoh:
02001a0000000000
dibaca:
02 = Shift
1a = W
8. Jalankan script usb_hid_decoder.py:
`python3 usb_hid_decoder.py`
